# 3-Link 2D Robotic Arm Simulation

A Python-based simulation of a three-link robotic arm, featuring interactive joint control and inverse kinematics for target positioning.

## Project Overview

This project involves the development of a 2D robotic arm simulation consisting of three interconnected links.

The simulation provides an interactive environment for exploring robotic arm movement, joint positioning, and inverse kinematics.

Users can manipulate the arm through interactive controls and specify target positions for the end effector.

## Features

* Three-link robotic arm simulation.
* Interactive joint angle adjustment.
* Inverse kinematics for target positioning.
* Real-time visualization of arm movement.
* Interactive controls for experimenting with different configurations.

## Technologies Used

* Python
* NumPy
* Matplotlib

## Installation and Setup

### 1. Clone the repository

```bash
git clone YOUR_REPOSITORY_URL
```

### 2. Navigate into the project folder

```bash
cd 3-Link-2D-Robotic-Arm
```

### 3. Install the required dependencies

```bash
pip install -r requirements.txt
```

### 4. Run the simulation

```bash
python main.py
```
